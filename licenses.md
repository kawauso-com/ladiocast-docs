# Included libraries

Ladiocast uses the following libraries (their `COPYING` files are in the folders under `Ladiocast.app/Contents/Resources/LibraryCopyings/`):

libshout  
[https://www.icecast.org/](http://www.icecast.org/)

libogg; libvorbis; libvorbisenc  
[https://www.xiph.org/](https://www.xiph.org/)

opus  
[https://www.opus-codec.org/](http://www.opus-codec.org/)

lame  
[https://lame.sourceforge.net/](http://lame.sourceforge.net/)

librtmp  
<https://rtmpdump.mplayerhq.hu/>
