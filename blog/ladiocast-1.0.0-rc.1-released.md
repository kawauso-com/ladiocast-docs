# Ladiocast 1.0.0-rc.1 Released

![Join the LadioCast beta - TestFlight - Apple](/images/Join-the-LadioCast-beta-TestFlight-Apple.png)

I have released Ladiocast 1.0.0-rc.1, the second release candidate, and the test continues on App Store TestFlight.
If you would like to take part in the test, please proceed from
https://ladiocast-docs.kawauso.com/testing

Changes from version 1.0.0-rc.0 to 1.0.0-rc.1 are as follows:

* Fixed a bug that ReadMe and ChangeLog in the Help menu were blank when the app was launched in a language other than English or Japanese (English is now shown).
* Unified the wording of the Main and Aux output labels across the localizations.

Help > ReadMe and ChangeLog have English and Japanese versions only. In rc.0, the other eight languages showed an empty window. Now they show the English version.
Please also look at the Main and Aux labels in the mixer window, and tell me about text that is cut off, overlaps or reads unnaturally, with a screenshot if you can.

When reporting a problem, please include your macOS version, Mac model (Intel or Apple silicon), the language the app is shown in, the audio devices you used, the streaming server and format, and any message shown by the app. How to report crashes, bugs and requests: https://ladiocast-docs.kawauso.com/feedback

Thank you for your help.
