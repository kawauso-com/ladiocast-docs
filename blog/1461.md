# Ladiocast 1.0.0-alpha.0 Released

![Join the LadioCast beta - TestFlight - Apple](/images/Join-the-LadioCast-beta-TestFlight-Apple.png)

Thank you very much for waiting so patiently for eight long years, ever since I released 0.13.0 in October 2018.
I am starting to test Ladiocast Version 1.0.0-alpha.0 on App Store TestFlight.
If you would like to take part in the test, please proceed from
https://ladiocast-docs.kawauso.com/testing

Changes from version 0.13.0 to 1.0.0-alpha.0 are as follows:

* Supports macOS 13 Ventura and later.
* Rebuilt as a universal app for Intel x86_64 and Apple silicon.
* Rewrote RTMP Streamer to use librtmp.
* Added HE-AAC and MP3 encoding formats to RTMP Streamer, in addition to AAC.
* Updated the libmp3lame library to version 3.101.
* Changed the default system sample rate from 44,100 Hz to 48,000 Hz.
* Removed the Character Set selection from Icecast Streamer.
* Fixed a bug that disconnecting just after a communication error could hang.
* Fixed a bug that a monaural input device was not automatically mapped to both the left and right channels.
* Updated the libopus library to version 1.6.1.

The changes are wide-ranging, but most of them concern behavior, so you may be surprised to find that the UI has hardly changed.

Also, the name of the application has been changed from LadioCast to Ladiocast.
The old name may still be used in places that cannot be changed, or that I have forgotten to change.

With this release, information about Ladiocast will be moving from https://blog.kawauso.com/ladiocast to https://ladiocast-docs.kawauso.com/blog/.

Finally, I would like to express my heartfelt thanks to Anthropic Claude Sonnet 5.5, whose awe-inspiring abilities made an enormous contribution to getting this release out the door.
