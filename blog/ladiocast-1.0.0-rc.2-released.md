# Ladiocast 1.0.0-rc.2 Released

![Join the Ladiocast beta - TestFlight - Apple](/images/Join-the-Ladiocast-beta-TestFlight-Apple.png)

I have released Ladiocast 1.0.0-rc.2, the third release candidate, and the test continues on App Store TestFlight.
If you would like to take part in the test, please proceed from
https://ladiocast-docs.kawauso.com/testing

Changes from version 1.0.0-rc.1 to 1.0.0-rc.2 are as follows:

* Added an error message for RTMPE and RTMPTE URLs in RTMP Streamer, which are not supported (use rtmp:// or rtmps://).
* Removed the leftover Character Set field from the Icecast Streamer window.

If you stream to an rtmpe:// URL, you will now see a message asking you to use rtmp:// or rtmps://.
Please also open each streamer window and tell me about text that is cut off, overlaps or sits in an odd position, with a screenshot if you can.

When reporting a problem, please include your macOS version, Mac model (Intel or Apple silicon), the language the app is shown in, the audio devices you used, the streaming server and format, and any message shown by the app. How to report crashes, bugs and requests: https://ladiocast-docs.kawauso.com/feedback

Thank you for your help.
