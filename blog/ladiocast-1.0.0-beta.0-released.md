# Ladiocast 1.0.0-beta.0 Released

![Join the LadioCast beta - TestFlight - Apple](/images/Join-the-LadioCast-beta-TestFlight-Apple.png)

I have upgraded Ladiocast 1.0.0 from alpha.0 to beta.0, and the test continues on App Store TestFlight.
If you would like to take part in the test, please proceed from
https://ladiocast-docs.kawauso.com/testing

Changes from version 1.0.0-alpha.0 to 1.0.0-beta.0 are as follows:

* Improved the audio quality of the mixer.

This time, the only change concerns the internal behavior of the mixer.
Specifically, the processing that matches the audio of the input and output devices to Ladiocast's own clock has been newly reimplemented.

When reporting a problem, please include your macOS version, Mac model (Intel or Apple silicon), the audio devices you used, the streaming server and format, and any message shown by the app. How to report crashes, bugs and requests: https://ladiocast-docs.kawauso.com/feedback

Thank you for your help.
