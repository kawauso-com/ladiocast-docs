# Ladiocastとは

LadiocastはMac OS X上で動作するインターネットラジオ放送ソフトウェアです。以下のような特徴を持っています。

- Icecast 2、SHOUTcast v1、RTMPの各形式による音声放送に対応

- 複数のサーバーへ同時に音声出力を送信することが可能

- エンコーディングフォーマットとしてOgg Vorbis・MP3・AAC・HE-AAC・Ogg Opus・Ogg PCMに対応

- 4イン/4アウト/4バスのミキサーを装備し、サウンド入出力デバイスを独立に選択可能

- SSL対応

- ユニバーサルバイナリ実行形式、動作対応OS Mac OS X 10.6 以降

## Ogg Opusエンコーディングを使用する際の注意

現在のところLadiocastのシステムサンプルレートが48000 (デフォルト 44100)になっていることが必要になります。 システムサンプルレートとは各ストリーマーウィンドウ上にあるエンコーディングサンプルレートではなく、設定パネルにあるサンプルレートのことです。 さらに設定パネル上の値を変更した場合はLadiocastを再起動する必要があります。

## Ogg PCMエンコーディングを使用する際の注意

LadiocastのOgg PCMエンコーディングフォーマットの仕様は<https://wiki.xiph.org/OggPCM>に従っていますが、数値については(Oggの他の仕様に従って)*リトルエンディアン*で表現されています。

サンプルの値はIEEE Float 32-bitリトルエンディアン形式で、サンプルレートはシステムサンプルレートと同一に設定されます。
