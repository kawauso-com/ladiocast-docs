# Ladiocast 1.0.0-beta.0 リリース

![Join the LadioCast beta - TestFlight - Apple](/images/Join-the-LadioCast-beta-TestFlight-Apple.png)

Ladiocast 1.0.0 を alpha.0 から beta.0 へバージョンアップし、App Store TestFlight にて引き続きテストを行っています。
このテストに参加される方は
https://ladiocast-docs.kawauso.com/ja/testing
よりお進みください。

バージョン1.0.0-alpha.0から1.0.0-beta.0への変更点は以下のとおりです。

* ミキサーの音質を改善

今回の変更はミキサーの内部動作に関するもののみになります。
具体的には入力デバイスと出力デバイスの音声を Ladiocast 自身のクロックに合わせる処理について新しく実装し直されています。

問題を報告いただく際は、macOS のバージョン、Mac の機種(Intel か Apple silicon)、使用したオーディオデバイス、配信先のサーバーと形式、アプリが表示したメッセージを添えてください。クラッシュ、不具合、ご要望の送り方はこちらをご覧ください: https://ladiocast-docs.kawauso.com/ja/feedback

よろしくお願いします。
