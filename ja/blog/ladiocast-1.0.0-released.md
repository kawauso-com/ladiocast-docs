# Ladiocast 1.0.0 リリース

![Ladiocast 1.0.0 released in MAS](/images/Ladiocast-1.0.0-released-in-MAS.png)

Ladiocast 1.0.0 を [Mac App Store](https://apps.apple.com/app/ladiocast/id411213048) でリリースしました。2018年10月の0.13.0以来のアップデートです。長い間お待たせしました。また、TestFlight でのテストにご参加いただいた皆さま、ありがとうございました。

リリース候補版のテストは終了しました。アプリ本体は 1.0.0-rc.2 から変更ありません。

バージョン0.13.0から1.0.0への変更点は以下のとおりです。

* macOS 13 Ventura以降に対応
* Intel x86_64とApple siliconのユニバーサルアプリとして再構築
* RTMPストリーマーをlibrtmpを使うように書き換え
* RTMPストリーマーに、AACに加えてHE-AACとMP3のエンコード形式を追加
* libmp3lameライブラリをバージョン3.101に更新
* libopusライブラリをバージョン1.6.1に更新
* システムサンプルレートのデフォルトを44,100Hzから48,000Hzに変更
* Icecastストリーマーから文字セットの選択を削除
* ミキサーの音質を改善
* ドイツ語、フランス語、スペイン語、イタリア語、韓国語、ブラジルのポルトガル語、簡体字中国語、繁体字中国語のローカライズを追加
* 通信エラーの直後に切断するとハングすることがある不具合を修正
* モノラルの入力デバイスが左右のチャンネルの両方に自動的に割り当てられない不具合を修正
* 選択したオーディオデバイスを開始できないと起動時に異常終了する不具合を修正（警告を表示して「デバイスなし」に設定）

全体は[変更履歴](/ja/changelog)をご覧ください。

クラッシュ、不具合、ご要望の送り方はこちらをご覧ください: https://ladiocast-docs.kawauso.com/ja/feedback

最後に当リリースに漕ぎ着けるまでに多大な貢献をしてくれた Anthropic Claude Sonnet 5.5 と Opus 5.5 に大いなる謝辞を贈りたいと思います。
