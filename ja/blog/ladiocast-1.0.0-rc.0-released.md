# Ladiocast 1.0.0-rc.0 リリース

![Join the LadioCast beta - TestFlight - Apple](/images/Join-the-LadioCast-beta-TestFlight-Apple.png)

Ladiocast 1.0.0 を beta.0 からリリース候補版の rc.0 へバージョンアップし、App Store TestFlight にて引き続きテストを行っています。
このテストに参加される方は
https://ladiocast-docs.kawauso.com/ja/testing
よりお進みください。

バージョン1.0.0-beta.0から1.0.0-rc.0への変更点は以下のとおりです。

* ドイツ語、フランス語、スペイン語、イタリア語、韓国語、ブラジルのポルトガル語、簡体字中国語、繁体字中国語のローカライズを追加
* 選択したオーディオデバイスを開始できないと起動時に異常終了する不具合を修正（警告を表示して「デバイスなし」に設定）

Ladiocastの言語設定をカスタマイズするにはシステム設定を立ち上げて一般 > 言語と地域 > アプリケーションと進みリストにLadiocastを追加して言語を選択します。
ウインドウ、メッセージを見て、文字が切れている、重なっている、不自然な表現になっているところがあれば、できればスクリーンショットを添えて教えてください。

起動時の異常終了は、テスターの方からのクラッシュレポートで見つかりました。beta.0 では、前回選んだオーディオデバイスを開始できないと、起動するたびに異常終了していました。このビルドでは、警告を表示してそのデバイスを「デバイスなし」に設定し、そのまま動き続けます。この警告が表示された場合は、表示された文をすべて、デバイスとその接続方法とあわせてお送りください。

問題を報告いただく際は、macOS のバージョン、Mac の機種(Intel か Apple silicon)、アプリの表示言語、使用したオーディオデバイス、配信先のサーバーと形式、アプリが表示したメッセージを添えてください。クラッシュ、不具合、ご要望の送り方はこちらをご覧ください: https://ladiocast-docs.kawauso.com/ja/feedback

よろしくお願いします。
