# Ladiocast 1.0.0-rc.1 リリース

![Join the Ladiocast beta - TestFlight - Apple](/images/Join-the-Ladiocast-beta-TestFlight-Apple.png)

Ladiocast 1.0.0 のリリース候補版の2つ目、rc.1 をリリースし、App Store TestFlight にて引き続きテストを行っています。
このテストに参加される方は
https://ladiocast-docs.kawauso.com/ja/testing
よりお進みください。

バージョン1.0.0-rc.0から1.0.0-rc.1への変更点は以下のとおりです。

* 英語と日本語以外の言語で起動すると、ヘルプメニューのReadMeとChangeLogが空になる不具合を修正（英語版を表示）
* 各言語のローカライズで、メイン出力とAux出力の表記を統一

ヘルプ > ReadMe と ChangeLog は、英語版と日本語版しかありません。rc.0 では、そのほかの8つの言語で空のウインドウが表示されていました。このビルドでは英語版が表示されます。
あわせて、ミキサーのウインドウの Main と Aux の表記を見て、文字が切れている、重なっている、不自然な表現になっているところがあれば、できればスクリーンショットを添えて教えてください。

問題を報告いただく際は、macOS のバージョン、Mac の機種(Intel か Apple silicon)、アプリの表示言語、使用したオーディオデバイス、配信先のサーバーと形式、アプリが表示したメッセージを添えてください。クラッシュ、不具合、ご要望の送り方はこちらをご覧ください: https://ladiocast-docs.kawauso.com/ja/feedback

よろしくお願いします。
