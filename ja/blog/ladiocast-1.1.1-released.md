# Ladiocast 1.1.1 リリース

![Ladiocast released in MAS](/images/Ladiocast-in-MAS.png)

Ladiocast 1.1.1 を [Mac App Store](https://apps.apple.com/app/ladiocast/id411213048) でリリースしました。1.1.1-beta.0、1.1.1-beta.1、1.1.1-beta.2 の TestFlight でのテストにご参加いただいた皆さま、ありがとうございました。

ベータ版のテストは終了しました。アプリ本体の 1.1.1-beta.2 からの変更は小さな修正1つだけです。ストリーマーウィンドウの“イベント”タブで「スクリプトを選択…」のファイルダイアログをキャンセルしたときに、メニューが選択されていた項目に戻るようにしました。

バージョン1.1.0から1.1.1への変更点は以下のとおりです。

* 入力デバイスの開始のたびに最初の0.8秒を捨てて、Macのオーディオジャックから入る開始直後のノイズが出ないように変更
* Icecastストリーマーで、Ogg形式の配信が自動再接続後にリスナーに届かなくなっていたのを修正
* IcecastストリーマーとShoutcastストリーマーで、曲名メタデータの文字セットをUTF-8に固定し、曲名の更新に失敗しても配信を続けるように、また再接続中に切断したらすぐ止まるように変更
* RTMPストリーマーで、AACパケットやMP3フレームを1つずつタグにして送り、タイムスタンプを時計ではなく送ったオーディオの量から付けるように変更
* Ogg OpusのVBRモードで品質レベルが効いていなかったのを修正
* システムサンプルレートが48000 Hzを超えるときなど、エンコーダーが対応しないAACの設定で内部エラーになっていたのを、理由がわかるエラーメッセージに変更
* 入力デバイスのバッファサイズが大きくなったときのバッファあふれ、デバイスの切り替えが反映されないことがある問題、接続し直すときのメモリリーク、killコマンドで終了したときにLoopbackデバイスが残る問題などの不具合を修正

このバージョンに新しい機能はなく、ストリーマーとオーディオデバイスまわりの修正版です。
ノイズの出ないデバイスも含めて、すべての入力デバイスで選択直後の0.8秒が無音になります。
Ogg Vorbis や Ogg Opus でサーバーとの接続が切れたときは、Ladiocast が再接続したあと、再生中だったリスナーは再生し直す必要があるかもしれません。
Icecast や SHOUTcast のサーバーやリスナーが、曲名の文字セットとして Shift_JIS など別のものを前提にしていた場合はお知らせください。

全体は[変更履歴](/ja/changelog)をご覧ください。
